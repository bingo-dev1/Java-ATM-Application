# Java ATM Application

A Java-based ATM application that simulates basic banking operations through a graphical user interface.

## Features

- Create a new account
- User login
- Check account balance
- Deposit money
- Withdraw money
- Transfer money
- View transaction history
- Change PIN
- Logout

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- VS Code

## Project Structure

The application is organized into different Java classes responsible for accounts, transactions, ATM operations, and graphical user interfaces.

## How to Run

1. Download or clone the repository.
2. Open the project in VS Code or another Java IDE.
3. Compile the Java source files.
4. Run `Main.java`.
5. Follow the instructions in the application.

## Purpose

This project was developed to practice Java programming, Object-Oriented Programming, GUI development, file handling, and software development concepts.
